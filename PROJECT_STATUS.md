> **Контекст передачи проекта (Handoff Document для Gemini / Antigravity на macOS)**  
> **Дата формирования**: 1 ноября 2026 года  
> **Репозиторий**: `https://github.com/AAAbdullo/beauty_salon.git` (ветка `main`)

## 1. Стек и окружение разработки

* **Фреймворк**: Flutter 3.x (Dart 3.x), Material 3.
* **Шрифты**: Google Fonts `Manrope` (зафиксирован на `google_fonts: ^6.2.1` во избежание конфликтов TextTheme).
* **Карты**: **Yandex MapKit Full SDK** (`yandex_mapkit: ^4.3.0`, режим `full`). Нативный ключ для Ташкента: `a7b20b8e-db40-4187-9f36-3e3c1a8d5db4`.
* **QR**: `qr_flutter: ^4.1.0` (генерация клиентского динамического QR), `mobile_scanner: ^5.2.3` (сканер визитов в кабинете мастера).
* **Архитектурный подход**: Feature-first, чистая изоляция бизнес-логики и UI.
* **Состояние данных сейчас**: Реактивный синглтон-сервис `AppStateService` (`ChangeNotifier`) + типизированные мок-репозитории (`SalonsRepository`, `MastersRepository`).
  * **ВАЖНОЕ ПРАВИЛО**: UI не зависит от бэкенда напрямую. Все эндпоинты, DTO и Query-параметры соответствуют будущему NestJS API (документация: NestJS 10, PostgreSQL + PostGIS, Redis 7). При подключении бэкенда переписываются только внутренности репозиториев/сервисов на вызовы `Dio`, код UI-экранов остаётся нетронутым.
* **Статус сборки и линтера**: `flutter analyze` — **0 issues** (0 errors, 0 warnings).

## 2. Специфика iOS (для запуска на macOS)

1. **CocoaPods**:
   В проекте подключен Yandex MapKit Full. После клонирования на Mac обязательно:
   ```bash
   flutter pub get
   cd ios
   pod install --repo-update
   cd ..
   ```
2. **Инициализация Yandex MapKit в iOS (`ios/Runner/AppDelegate.swift`)**:
   Необходимо убедиться, что ключ инициализирован перед вызовом регистратора:
   ```swift
   import UIKit
   import Flutter
   import YandexMapsMobile

   @UIApplicationMain
   @objc class AppDelegate: FlutterAppDelegate {
     override func application(
       _ application: UIApplication,
       didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?
     ) -> Bool {
       YMKMapKit.setApiKey("a7b20b8e-db40-4187-9f36-3e3c1a8d5db4")
       GeneratedPluginRegistrant.register(with: self)
       return super.application(application, didFinishLaunchingWithOptions: launchOptions)
     }
   }
   ```
3. **Разрешения в `ios/Runner/Info.plist`**:
   - `NSCameraUsageDescription` (для сканирования QR мастера через камеру).
   - `NSLocationWhenInUseUsageDescription` (для геопозиции на Яндекс Картах).

## 3. Что уже ПОЛНОСТЬЮ реализовано (Статус: 100%)

### Клиентский интерфейс («Mijoz»):
* **M-01 & M-02 (Авторизация и онбординг)**: Маска номера `+998 XX XXX XX XX`, таймер OTP `00:45`, ввод SMS-кода, 3-шаговая анкета профиля (Имя, Пол, Дата рождения). Демо-логины для быстрого тестирования: `client` / `12345678` и `master` / `12345678`.
* **M-03 (Интерактивная карта Ташкента)**: Полноценный векторный Yandex MapKit Full, кастомные пины салонов, плавающая нижняя шторка (`DraggableScrollableSheet`) с карточками салонов и расстоянием.
* **M-04 & M-05 (Каталог, фильтры и живой поиск)**: Модальная шторка `SearchFilterModal`:
  * Чипсы 10 районов Ташкента (Мирабадский, Юнусабадский, Чиланзарский и др.).
  * Тумблеры: «Только для женщин» (*Faqat ayollar учун*), «Выезд на дом» (*Uyga chiqish*), «Свободно сегодня» (*Bugun bo'sh*), «По кредитам» (*Kredit bilan*).
  * RangeSlider цен, живой поиск карточек без задержек.
* **M-06 (Детальная страница салона)**: Сливер-шапка с фотогалереей, удобствами, 4 табами (*Услуги, Мастера, Отзывы, О салоне*).
* **M-07 (Страница мастера — Usta sahifasi)**: Аватарка мастера, онлайн-смена, бейдж опыта (стаж), 3 таба (*Услуги, Портфолио работ, Отзывы*), кнопка прямой записи к мастеру.
* **M-08 (Бронирование и Hold Timer 10 мин)**: 7-дневный календарь, сетка слотов, выбор способа оплаты (Кредиты / Онлайн / В салоне), **интерактивный 10-минутный таймер удержания слота** с предупреждением об истечении и кнопкой продления.
* **M-09 (Способы оплаты)**: Списание 34 кр. с баланса, эмуляция узбекских шлюзов (Click, Payme, Uzum), оплата при визите в салоне.
* **M-10 (Мои записи и перенос времени)**: 3 таба (*Активные, Прошедшие, Отмененные*), отмена с автовозвратом кредитов на баланс, **интерактивная шторка переноса времени визита (Reschedule)** с выбором новых дней и слотов без списания кредитов.
* **M-11 (Личный динамический QR)**: Модалка `ClientQrModal`, динамическая генерация QR (`qr_flutter`) для предъявления администратору, автотаймер обновления 60 секунд.
* **M-13 (Оценка и отзывы)**: Шторка `LeaveReviewModal` в табе «Прошедшие»: 1–5 звезд с эмодзи-статусом, мультиселект тегов качества/сервиса, поле комментария, мгновенное отображение оценки в карточке визита.
* **M-14 (Подписка и баланс кредитов)**: Тарифы Lite (60 кр), Standart (120 кр), Premium (250 кр), прогресс-бар расхода, покупка пакетов, заморозка подписки на 7–30 дней.
* **M-15 (Избранное)**: Экран `FavoritesScreen` с 2 табами (*Салоны* и *Мастера*), переключение сердечком в шапках салона и мастера, реактивный счетчик в профиле.

### Кабинет Мастера («Usta»):
* **S-01 (Дашборд мастера)**: Тумблер смены «На смене / Перерыв», карточка ближайшего клиента с таймером («Через 20 мин»), дневная выручка, счетчик клиентов.
* **S-04 (График работы)**: Управление днями недели, открытие/закрытие индивидуальных слотов мастера.
* **QR Scanner**: Сканер камерой через `mobile_scanner` + кнопка быстрой тестовой валидации, экраны успеха/ошибки.
* **S-10 (Финансы мастера)**: Месячный доход, автоматический расчет комиссии сервиса 10%, чистая выплата.

## 4. Что предстоит сделать ДАЛЬШЕ (Бэклог приоритетных задач)

Следующие задачи в очереди согласно утвержденному плану:

1. **K-03 (Лимит: не более 4 записей по кредитам в один салон в месяц)**:
   * **Суть**: Согласно правилам 1Fit/ClassPass, один клиент не может записаться по кредитам в один и тот же салон чаще 4 раз за календарный месяц (во избежание злоупотребления абонементом).
   * **Что сделать**: В `AppStateService` добавить проверку счетчика броней текущего месяца для выбранного салона. Если $\ge 4$, при попытке выбрать «Оплата кредитами» показывать предупреждающий диалог и блокировать подтверждение, предлагая оплатить онлайн (Click/Payme/Uzum) или в салоне наличными/картой.
2. **S-06 (Walk-in клиент: быстрая запись мастера вне очереди)**:
   * **Суть**: Клиент пришел с улицы без брони через приложение или позвонил напрямую администратору.
   * **Что сделать**: В дашборде мастера (`master_dashboard_screen.dart`) добавить кнопку «Записать клиента с улицы (Walk-in)». Модальное окно: ввод имени, телефона `+998`, выбор услуги, фиксация оплаты в кассе без списания кредитов подписки.
3. **M-12 (Центр уведомлений / Пуши)**:
   * **Суть**: Сейчас колокольчик в шапке кликабелен и показывает бейдж «3».
   * **Что сделать**: Шторка/экран со списком уведомлений: напоминание о записи за 24 ч, за 2 ч, подтверждение визита, новости акций.
4. **K-05 & K-06 (Штрафы за позднюю отмену и компенсация отмены салоном)**:
   * Если клиент отменяет бронь менее чем за 4 часа до визита $\to$ сгорание кредита.
   * Если бронь отменил сам салон $\to$ возврат кредитов + 10 бонусных кредитов на баланс клиента.
